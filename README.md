# 角色卡 · 预设与全局世界书绑定器 v0.2.3

适用于 SillyTavern 的轻量前端扩展。按角色卡**本地头像文件名**区分同名角色，自动切换当前 API 的生成预设和/或全局世界书，两个功能可分别启用。

## GitHub 仓库安装（推荐）

1. 在 SillyTavern 的“扩展”菜单找到“安装扩展”。
2. 粘贴仓库地址：`https://github.com/yuyun-akf/st-character-preset-binder.git`。
3. 安装后刷新酒馆，在扩展设置中找到“角色卡 · 预设与世界书绑定器”。

## 本地 ZIP 安装

1. 解压 ZIP，确保得到 `st-character-preset-binder` 文件夹，其中有 `manifest.json`、`index.js`、`style.css`。
2. 把整个文件夹放到 `SillyTavern/public/scripts/extensions/third-party/` 下。
3. 刷新酒馆页面，打开顶部“扩展”设置，展开“角色卡 · 预设与世界书绑定器”。

在一些部署或沙盒环境中，用户不能直接操作该文件夹；这时可以把这些文件上传到自己控制的 GitHub 仓库，再在酒馆的“安装扩展”里填 **Git 仓库 URL**。ZIP 文件本身不是可直接安装的 Git URL，推荐使用本仓库地址安装。

**从 v0.1.0 升级**：同名文件夹中替换 `index.js`、`style.css`、`manifest.json` 和 `README.md`，刷新酒馆。原有预设绑定保存在扩展设置里，v0.2.0 会沿用；建议先备份酒馆数据和用户设置。

## 使用

1. 进入角色卡的单人聊天，如“梨子（修仙版）”。
2. **预设（可选）**：从列表中选一个预设，点击“保存预设绑定”。不想绑定预设则不操作这一项，或点击“解除预设绑定”。
3. **全局世界书（可选）**：勾选“启用这张卡的全局世界书自动切换”，在下面勾选一本或多本世界书，点击“保存世界书设置”。
4. 再切换到同名的“梨子（现代版）”，分别设置另一套预设及世界书。
5. 切换角色卡或打开该卡的其他聊天时，自动应用对应的绑定。

### 世界书绑定的三个状态（务必区分）

- **未绑定**（开关没开启/点击解除世界书绑定）：切换到这张卡时 **完全不更改当前全局世界书**。如果上一张卡启用了修仙世界书，它会继续保持开启，直到你手动修改或打开另一张**绑定了世界书**的卡。
- **绑定一本或多本**：将当前所有**全局世界书**替换为勾选的完整列表。其他原本启用的全局世界书会关闭。如需保留通用世界书，需一并勾选。
- **绑定空列表**（勾选开关，但下方所有书均未勾选，并保存）：进入该角色时关闭全部**全局世界书**。这不是“未绑定”。

此扩展**只切换全局世界书**，不会删除/改写世界书文件，也不会覆盖角色卡自带的主世界书、辅助世界书、聊天级世界书或 Persona 世界书。酒馆的世界书扫描机制仍照常运行。

## 安全与兼容性

- 一张角色卡可以绑定多个全局世界书；预设根据当前 API 分别存储，插件不会自动改变 API、模型、代理或连接配置。
- 群聊不触发切换；未绑定内容不会被修改。
- 目标世界书被删除或改名：**跳过整组世界书切换**，保持当前全局书，不应用不完整的列表。目标预设不存在时同样跳过预设切换。
- 手动修改后，当前聊天可以临时使用新值；下次进入绑定角色时再自动恢复。
- 角色卡通过本地 `avatar` 文件名识别，同名但不同文件可区分。删除并重新导入、在其他酒馆迁移后如文件名变化，需重新绑定。
- 设置保存在 SillyTavern 用户扩展设置中，**不会写入角色卡 PNG**，也不会上传到第三方服务器。
- v0.2.2：移除 v0.2.1 错误的深灰色信息卡、强制背景色和模糊效果；使用酒馆原生抽屉的显示/隐藏机制，并由用户现有主题决定色彩。
- v0.2.1：采用 SillyTavern 原生抽屉结构。
- v0.2.0 使用官方 `world-info.js` 导出的世界书列表及酒馆原生世界书选择控件，切换会触发原生持久化与世界书更新事件。
- 已执行 JavaScript 语法及模拟环境测试，但**未在你的实际酒馆版本、移动端界面与插件组合中安装验收**。先备份，遇到不兼容问题可提供浏览器控制台报错。
- 若酒馆原生的“角色名匹配预设自动切换”仍在开启，它可能与本扩展冲突；建议关闭原生同名自动切换后测试本扩展。

- v0.2.3 移除扩展容器额外的上下外边距，使折叠栏更贴近其他扩展；保留主题原生配色。
